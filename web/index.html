计量表

权重是 waifu2x（CUnet / Swin-UNet）与 Real-ESRGAN、AnimeSharp 的 ONNX 版本，全部在你本机推理，图片不出这台机器。

两个必须说清的坑

一、waifu2x 系在 DirectML 上会算错。不报错，但结果是花的。所以程序在装载时拿同一块输入同时在 GPU 和 CPU 上各跑一遍、比对数值， 不一致就退回 CPU，结论缓存在 models/.device_probe.json。Real-ESRGAN 与 AnimeSharp 在 DirectML 上正常，会留在 GPU 上跑。

二、各族的输入输出约定不一样。waifu2x 会吃掉一圈边界像素（CUnet 是 out = 2×in − 72，Swin 是 out = 2×in − 32）， Real-ESRGAN 系则是干净的 out = 4×in。程序启动时用小图试探两个尺寸、拟合出 out = a×in + b，据此决定外扩与裁切，不写死魔数。
