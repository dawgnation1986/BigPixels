计量表

权重为 waifu2x（CUnet / Swin-UNet）与 Real-ESRGAN、AnimeSharp 的 ONNX 版本，全部在本机推理，图片不会离开本机。

两点必须说明的限制

一、waifu2x 系在 DirectML 上会算出错误结果。过程不报错，但输出是花的。因此程序在装载时用同一块输入分别在 GPU 与 CPU 上各跑一遍并比对数值， 不一致则退回 CPU，结论缓存在 models/.device_probe.json。Real-ESRGAN 与 AnimeSharp 在 DirectML 上正常，会留在 GPU 上运行。

二、各族的输入输出约定不一致。waifu2x 会扣掉一圈边界像素（CUnet 是 out = 2×in − 72，Swin 是 out = 2×in − 32）， Real-ESRGAN 系则是干净的 out = 4×in。程序启动时用小图试探两个尺寸，拟合出 out = a×in + b，据此决定外扩与裁切，不写死魔数。
